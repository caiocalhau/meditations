# Synthetic weekly-review examples

These artifacts use invented delivery/retry work and hand-authored structured
drafts. The helper rendered them in a temporary vault; no model or real note was
used. They demonstrate formatting and state transitions, not a measured learning
benefit or independent evaluation of model quality.

1. [Synthetic daily input](synthetic-daily-note.md) contains a proposal, a mistaken
   personal explanation and a language error.
2. [First review](01-first-review.md) gives substantive evidence-linked analysis
   immediately and creates protected practice questions and response space.
3. [Response feedback](02-response-feedback.md) evaluates a later written answer
   while keeping the earlier question and exact personal answer visible.
4. [Delayed practice](03-delayed-practice.md) revisits the earlier practice in the
   next week, with a fresh question and evidence limits.

Source links show the private vault's expected daily/weekly layout. These staged
artifacts are displayed together here rather than installed as a live vault.
Do not copy their fingerprints into a real draft; obtain current ones through
`meditations weekly prepare`. Study the [weekly contract](../../docs/architecture/weekly-review.md)
and [semantic rubric](../../evals/weekly-review/README.md) for evidence boundaries.
